# Wedding Seating Optimizer: requirements fit for an AI implementer

This repository holds a product requirements document (PRD) for a wedding
seating optimizer, in two versions:

- `docs/original/wedding-seating-optimizer-requirements.md`: v0.1 as written
  by the E-gineering team lead. Never edited.
- `docs/requirements.md`: v0.2, rewritten so that an AI implementing agent can
  build from it without guessing. (Arrives in the first pull request.)

The exercise: take v0.1, remove every word with more than one reading, and
add the context an agent would otherwise have to invent. The change log
explains each edit.

Status: repo created 2026-09-16. Rewrite in progress.
